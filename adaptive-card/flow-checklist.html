B4

Data Operation · Filter array

กรองเอาเฉพาะงานที่ยังไม่ปิด

Rename เป็น: Filter Open

ขั้นตอนการตั้ง From field:
1. ที่ช่อง From ให้คลิกที่ช่องข้อมูล
2. ด้านขวาจะเปิด panel หลังจากให้เลือก dynamic content
3. มองหา value — นี่คือชื่อของ output จาก action List_rows_present_in_a_table
4. ทั้งหมดแถวข้อมูลจาก Excel จะอยู่ใน property นี้ ซึ่งต้องใช้ filter ต่อไป

From — ผลลัพธ์เมื่อคลิกเลือก value
body('List_rows_present_in_a_table')?['value']

ทำไมต้อง .value?

Action "List rows present in a table" คืนผลลัพธ์ที่มี object หลายๆ ส่วน ส่วน value คือตัวที่บรรจุ array แถวจากตาราง — ยึดเอาส่วนนี้เท่านั้น

เงื่อนไข — กด Edit in advanced mode ก่อนวาง
@and(not(equals(item()?['Status'],'Closed')),not(equals(item()?['Status'],'Cancelled')))

โครงสร้าง Flow ทั้งหมด

⏰ Recurrence                      ทุกวัน 08:00 (Bangkok)
│
├─ 📊 List rows present in a table     Excel: JobTable  + Pagination
│
├─ 🔍 Filter Open                      ตัดงานที่ปิดแล้วออก
├─ 🔍 Filter Critical                  นับ Critical
├─ 🔍 Filter Major                     นับ Major
├─ 🔍 Filter Minor                     นับ Minor
│
├─ 🔀 Sorted Jobs      (Compose)       union() → Critical มาก่อน
├─ ✂️  Top Jobs         (Compose)       take(...,15)
├─ 🔢 Status Breakdown (Compose)       นับแยก Status ด้วย split()
│
├─ 🧱 Select Rows      (Select)        สร้าง ColumnSet 15 แถว   ★
├─ 🎴 Card JSON        (Compose)       ประกอบการ์ดทั้งใบ
│
└─ 💬 Post adaptive card in a chat or channel

Expression ทั้งหมดในที่เดียว

ใช้ที่Expression
Filter Open — Frombody('List_rows_present_in_a_table')?['value']
Filter Open — เงื่อนไข@and(not(equals(item()?['Status'],'Closed')),not(equals(item()?['Status'],'Cancelled')))
Filter Critical/Major/Minor — Frombody('Filter_Open')
Sorted Jobsunion(union(body('Filter_Critical'),body('Filter_Major')),body('Filter_Minor'))
Top Jobstake(outputs('Sorted_Jobs'),15)
Select Rows — Fromoutputs('Top_Jobs')
Teams — Adaptive Cardoutputs('Card_JSON')
จำนวนทั้งหมดlength(body('Filter_Open'))
จำนวนที่แสดงlength(outputs('Top_Jobs'))
จำนวนที่เหลือsub(length(body('Filter_Open')),length(outputs('Top_Jobs')))
วันที่แบบไทยformatDateTime(convertTimeZone(utcNow(),'UTC','SE Asia Standard Time'),'dd/MM/yyyy')

แก้ปัญหาที่เจอบ่อย

การ์ดขึ้นตัวอักษร ${jobs} ดิบ ๆ ไม่มีข้อมูล
เอาไฟล์ 01-card-template.json ไปใช้ใน Flow ซึ่งเป็นเวอร์ชันสำหรับ Designer เท่านั้น ให้เปลี่ยนไปใช้ 04-card-powerautomate.json ในขั้น B10 แทน
ขึ้น error: The template language expression … cannot be evaluated
ชื่อ action ไม่ตรงกับที่ expression อ้างถึง ไล่เช็กชื่อทุก action ให้ตรงกับที่ระบุในแต่ละขั้น จำไว้ว่าเว้นวรรคในชื่อจะกลายเป็น _ เช่น Filter Open → Filter_Open
ตารางบนการ์ดว่างเปล่า ไม่มีแถวเลย
เปิด Run history ดู output ของ Top Jobs ก่อน ถ้าว่างแปลว่าปัญหาอยู่ที่ Filter ถ้ามีข้อมูลแต่ Select Rows ว่าง แปลว่าช่อง From ผิด — ต้องเป็น outputs('Top_Jobs')
บางคอลัมน์ว่าง ทั้งที่ใน Excel มีข้อมูล
ชื่อคอลัมน์สะกดไม่ตรง เปิด Run history → ดู output ดิบของ Filter Open → คัดลอกชื่อ key มาใส่ใน item()?['...'] ให้ตรงทั้งตัวพิมพ์เล็กพิมพ์ใหญ่และเว้นวรรค
Create Time ขึ้นเป็นตัวเลข 46265.69
เซลล์ใน Excel เป็นชนิด Date ไม่ใช่ข้อความ กลับไปทำขั้น A2 เพิ่มคอลัมน์ช่วยด้วยสูตร =TEXT([@[Create Time]],"dd-mmm-yy hh:mm") แล้วชี้ Flow มาที่คอลัมน์ใหม่
Teams ไม่ส่งการ์ด หรือขึ้น error เรื่องขนาด
การ์ดใหญ่เกินขีดจำกัดของ Teams ประมาณ 28 KB ลดเลขในขั้น B7 จาก take(outputs('Sorted_Jobs'),15) เหลือ 10
ได้ข้อมูลแค่ 256 แถว ทั้งที่ไฟล์มีมากกว่านั้น
ยังไม่ได้เปิด Pagination กลับไปขั้น B3 → คลิก … บน action → Settings → Pagination = On → Threshold 5000
การ์ดแคบ ตารางอัดกันจนอ่านไม่ออก
ตรวจว่าใน Card JSON มีบรรทัด "msteams": { "width": "Full" } อยู่ใกล้ ๆ ด้านบน ถ้าหายไปการ์ดจะไม่ขยายเต็มความกว้างของ Teams
Status Breakdown ขึ้นเลข 0 ทุกตัว
รูปแบบ JSON ที่ string() คืนมาไม่ตรงกับคำที่ใช้ split เปิด Run history ดู output ดิบของ Filter Open แล้วแก้คำใน split() ให้ตรงกับที่เห็นจริง
