5

แยกกองตามความรุนแรง

Action · Filter array ×3

สร้าง Filter array อีก 3 อัน ทั้งหมด From = body('Filter_Open_Jobs') เหมือนกัน ต่างกันแค่เงื่อนไขใน advanced mode

Filter Critical
@equals(item()?['Priority'], 'Critical')
Filter Major
@equals(item()?['Priority'], 'Major')
Filter Minor
@not(contains(createArray('Critical','Major'), string(item()?['Priority'])))

ทำไม Minor ไม่ใช้ equals(...,'Minor')? เพราะเขียนแบบ ไม่ใช่ Critical และไม่ใช่ Major จะกวาดแถวที่ช่อง Priority ว่างหรือเป็น null เข้ามาด้วย (ในไฟล์ตัวอย่างมีอยู่ 1 แถว) ไม่งั้นงานนั้นจะหายไปจากรายงาน

ทั้ง 3 กองนี้เอาไว้นับตัวเลข KPI บนหัวการ์ดด้วย length(body('Filter_Critical')) และเพื่อนอีกสองตัว

6

เรียงลำดับ แล้วตัดเหลือ 12 แถว

Action · Compose → ชื่อ Compose_Top_Jobs

Power Automate ไม่มีปุ่ม Sort ให้ใช้ เลยใช้วิธี ต่อกองตามลำดับที่อยากได้ แทน: Critical มาก่อน ตามด้วย Major แล้วค่อย Minor จากนั้น take() เอาแค่ 12 แถวแรก

Inputs (แท็บ Expression)
take(union(body('Filter_Critical'), body('Filter_Major'), body('Filter_Minor')), 12)
ทำไมต้อง 12

วัดจากการ์ดชุดนี้จริง ๆ: โครงการ์ดเปล่า 4.7 KB + แถวละ ~1.24 KB

จำนวนแถวขนาดการ์ดผล
1017.1 KBปลอดภัย
1219.5 KBแนะนำ
1523.2 KBยังไหว
1826.9 KBเฉียดลิมิต
2029.4 KBการ์ดหาย

ชื่อ Site Name หรือชื่อคนภาษาไทยยาว ๆ ทำให้แต่ละแถวโตกว่านี้ได้ จึงเผื่อไว้ที่ 12 · ไฟล์ตัวอย่างมี 117 งาน ที่เหลือให้กดปุ่มไปดูใน Dashboard เอา

อยากโชว์บรรทัด "ยังมีอีก N รายการ" บนการ์ด ใช้สูตรนี้:

จำนวนที่ไม่ได้แสดง
sub(length(body('Filter_Open_Jobs')), length(outputs('Compose_Top_Jobs')))

union() จะตัดแถวที่ข้อมูลซ้ำกันทุกช่องออก — Job ID ไม่ซ้ำอยู่แล้วจึงปลอดภัย ถ้าไม่อยากให้ตัดเลยเปลี่ยนเป็น concat() แทน union()

ตรวจก่อนเปิดใช้จริง

บั๊กที่เจอใน Flow ตัวจริง · CMTRS_Daily_Job_Monitor_0800

ตรวจจากไฟล์ export .zip เทียบกับข้อมูลจริง 125 แถว — เจอ 5 จุด ตัวที่ทำให้การ์ดว่างคือข้อ 1

ต้นเหตุหลัก · ชื่อคีย์มี Enter ติดมาด้วย

ใน Select_Normalize_Jobs ช่องชื่อคีย์ทางซ้าย 7 จาก 8 ช่อง มีตัวขึ้นบรรทัดใหม่ติดท้าย กลายเป็น "Sub System\n" แทนที่จะเป็น "Sub System"

พอถึงขั้น Select_Job_Rows การ์ดไปเรียก item()?['Sub System'] (ไม่มี \n) จึงหาไม่เจอ → ได้ค่าว่าง → ตกไปใช้ค่าสำรอง '-' ทุกช่อง

สังเกตให้ดี: คอลัมน์ Status เป็นช่องเดียวที่ไม่มี \n ติดมา และเป็นช่องเดียวที่แสดงผลถูกต้องบนการ์ด — ตรงกันเป๊ะกับอาการที่เห็น

#จุดที่ผิดผลที่เห็นบนการ์ด
1Select_Normalize_Jobs — คีย์ 7 ตัวมี \n ต่อท้ายSub System / Job ID / Create Time / Province / Site Name ว่างเป็น - · Priority เป็น Minor ทุกแถว · Assign to เป็น Unassigned ทุกแถว
2Create Time ใช้ formatDateTime() แต่ค่าในไฟล์เป็น ข้อความ 15-Aug-26 16:43ถึงแก้ข้อ 1 แล้วก็ยังเสี่ยง Action ล้มด้วย error แปลงวันที่ไม่ได้
3Filter_Open_Jobs เงื่อนไขเป็น @equals(true,true)ไม่ได้กรองอะไรเลย งานที่ปิดแล้วก็หลุดเข้ามาด้วย
4Compose_Sorted_Jobs ชี้กลับไปที่ Filter_Open_Jobs ตรง ๆไม่ได้เรียงตามความรุนแรง · Filter_Critical/Major/Minor คำนวณทิ้งไว้เฉย ๆ ไม่มีใครใช้ → Critical 6 งานไม่เคยขึ้นการ์ดเลย เพราะโดน Minor 12 แถวแรกกินที่หมด
5Compose_RunTime คำนวณไว้แต่ไม่มี __RUN_TIME__ ในการ์ดบนการ์ดบอกแค่ "แสดง 12 รายการ" ไม่รู้ว่าจากทั้งหมดกี่งาน และข้อมูลสดแค่ไหน

สูตรที่แก้แล้ว

ถ้าจะแก้เองในหน้า Designer ให้ทำ 4 จุดนี้ (ข้อ 1 สำคัญสุด)

จุดที่ 1 · Select_Normalize_Jobs

คลิกในช่องชื่อคีย์ทางซ้ายทั้ง 7 ช่อง → กด End แล้ว Backspace จนเคอร์เซอร์ขยับขึ้นมาชิดตัวอักษรสุดท้าย → อย่ากด Enter ให้กด Tab ออกจากช่องแทน ชื่อที่ถูกต้องคือ Sub System · Job ID · Priority · Create Time · Status · Province Name · Site Name · Assign to

จุดที่ 2 · ค่าของคีย์ Create Time
if(empty(coalesce(item()?['Create Time'],'')),'—',if(contains(string(item()?['Create Time']),'T'),formatDateTime(item()?['Create Time'],'dd-MMM-yy HH:mm'),string(item()?['Create Time'])))

รับได้ทั้งกรณีเป็นข้อความจาก Excel และเป็น ISO datetime จาก SharePoint

จุดที่ 3 · Filter_Open_Jobs (advanced mode)
@not(contains(createArray('closed','completed','cancelled','resolved'),toLower(trim(coalesce(item()?['Status'],'')))))
จุดที่ 4 · Compose_Sorted_Jobs
concat(body('Filter_Critical'),body('Filter_Major'),body('Filter_Minor'))
ผลหลังแก้ (ทดสอบกับข้อมูลจริง 125 แถวแล้ว)

การ์ดขึ้นครบทั้ง 8 คอลัมน์ · 12 แถวแรกกลายเป็น Critical 6 งาน ตามด้วย Major 6 งาน · หัวการ์ดสรุปว่า แสดง 12 จาก 125 รายการ · Critical 6 · Major 23 · Minor 96 · ขนาดการ์ด 19.1 KB ยังห่างลิมิต 28 KB อยู่ 8.9 KB

หรือจะข้ามการแก้มือ ใช้ไฟล์ CMTRS_Daily_Job_Monitor_0800_FIXED.zip ที่แก้ให้แล้วก็ได้ — เข้า Power Automate › My flows › Import › Import Package (Legacy) อัปโหลดไฟล์ → ที่บรรทัด flow กด Select during import เลือก Update แล้วชี้ไป flow เดิม → ผูก connection ของ Excel และ Teams ให้ครบ → Import

การ์ดที่แก้แล้วยังชี้ไปที่ Group chat และไฟล์ Excel เดิมของคุณ ถ้าเปลี่ยนห้องหรือย้ายไฟล์ ต้องตั้งใหม่ในขั้นที่ 3 และขั้นที่ 9

  • ทดสอบก่อนส่งจริง — รัน npx serve . แล้วเปิด preview.html จะเรนเดอร์การ์ดจริงในเบราว์เซอร์ โหลดไฟล์ .xlsx ของคุณมาทดสอบ และคำนวณขนาดการ์ดเทียบลิมิต 28 KB ให้ดูก่อน
